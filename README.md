# Number Guessing Game CLI
A simple number guessing game implemented in Go. The player has to guess a randomly generated number within a certain range and has a limited number of attempts. If the player guesses the number correctly, they win; otherwise, they lose.

## Usage
```bash
./number-guessing
```

## Features
- Random number generation
- User input handling
- Feedback on guesses (too high, too low, correct)
- Limited number of attempts
- Replay option
